# Drop your images here

Everything is a plain filename lookup — no upload UI, just put files in this
folder with these exact names and every page will pick them up.

## Floating decorative photos (used across most pages)
- vflt1.jpg, vflt2.jpg, vflt3.jpg, vflt4.jpg, vflt5.jpg

## home.html
- home-photo.jpg (the one big photo box)

## you.html (5 photos)
- you1.jpg ... you5.jpg
- edit the `text` field per photo directly in you.html for the hover caption

## us.html (10 photos)
- wrap.jpg (the closed gift/photo box before it's tapped)
- us1.jpg ... us10.jpg
- edit the `text` field per photo directly in us.html for the caption under the carousel

## gallery.html (15 photos, no captions)
- gallery1.jpg ... gallery15.jpg

## sumsum.html
- qr.jpg (whatever QR code you want revealed at the end)

## wish.html
- no images needed — open wish.html and replace the placeholder <p> tags
  inside .letter-card with the actual letter

## home.html text
- open home.html and edit the `title` and `caption` variables near the
  bottom of the <script> tag
